Firebase setup

Paste your Firebase Web App configuration into the HTML's FIREBASE_CONFIG constant, then enable Firebase Realtime Database. For private control, sign in anonymously using Firebase Authentication. This file uses an anonymous authenticated session on each device.

For quick testing, use the same room ID in both URLs. Example: ?mode=controller&room=my-secret-room and ?mode=overlay&room=my-secret-room. The room ID is not a password.

Security note: the sample database rules below allow any authenticated user who knows the room ID to modify it. Use a private room ID and upgrade to owner-only writes for public use.

{"rules":{"rooms":{"$room":{".read":"auth != null",".write":"auth != null"}}}}
